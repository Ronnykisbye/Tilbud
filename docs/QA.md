# Kvalitetssikring – version 1

## Kontrolleret

- JSON-filer kan parses korrekt.
- JavaScript-filer har gyldig syntaks.
- CSS og HTML er opdelt i tydelige filer.
- Appen kræver ikke build-step og kan køre direkte på GitHub Pages.
- Demo-data dækker flere varer og områder.
- Koden er opdelt, så fejl kan rettes fil for fil.

## Kendte begrænsninger

- Priser er demo-data, ikke live-priser.
- GPS kan kun virke, hvis browseren giver tilladelse.
- PWA-installation afhænger af browserens regler.
- Rigtige API-nøgler må ikke placeres direkte i frontend-kode på GitHub Pages.
